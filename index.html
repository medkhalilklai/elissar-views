⚙️ Réglages & clé API

La clé est enregistrée uniquement dans ton navigateur (localStorage), elle n'est envoyée qu'à Google.

Chaque rafraîchissement consomme ~3 unités du quota gratuit (10 000 unités/jour).

❓ Comment obtenir une clé API YouTube (gratuit, ~5 min)
  1. Ouvre console.cloud.google.com et connecte-toi avec ton compte Google.
  2. En haut, clique sur le sélecteur de projet → Nouveau projet → nomme-le (ex. suivi-elissar) → Créer.
  3. Menu ☰ → API et services → Bibliothèque → cherche « YouTube Data API v3 » → clique Activer.
  4. Menu API et services → Identifiants → Créer des identifiants → Clé API.
  5. Copie la clé (commence par AIza), colle-la dans « Réglages » ci-dessus → Enregistrer & charger.

C'est gratuit : 10 000 unités de quota par jour, soit ~3 000 rafraîchissements. Si tu héberges le site en ligne, restreins la clé (Identifiants → ta clé → Restrictions de site web) à ton domaine.
